# Shanaf's Attire — Coming Soon page

## Publish on GitHub Pages
1. Create a new public repository on GitHub (e.g. `shanafs-attire`).
2. Upload everything in this folder (`index.html`, `assets/`, this README) to the repository root.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/shanafs-attire/`.

## Before publishing
- In `index.html`, replace `https://www.facebook.com/` with your Facebook page link (search for "Replace the link").
